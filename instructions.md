The project is a clone of this repo https://github.com/lopiksaa/carthage

Build me a desktop game launcher for Linux and Windows that looks like a shelf of game cartridges instead of a plain library list.

It should gather my games from Steam, Heroic, Lutris, Flatpak, Epic, Battle.net, Riot, and any games I add myself, then show them as nice collectible cards or cartridges. When I launch a game, I want it to animate into a dock or tray so it feels alive. If cover art is missing, use a simple printed label style instead of leaving it blank.

I also want an easy way to browse the Steam and Epic stores inside the app so I can compare prices without leaving it. Keep it usable without any account keys, but let me add optional SteamGridDB and Steam Web API keys later for better artwork and a fuller Steam library.

Make the setup and update flow feel simple, and let it run well from source too. If you need to look up current docs online, go ahead.
